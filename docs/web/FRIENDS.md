# Using Nuvio Web on iPhone

You need: an iPhone with Safari, a Nuvio account, and the invite code you were sent.

1. Open the Nuvio Web link in **Safari**.
2. Enter your **invite code** when asked. You only do this once on this phone.
3. **Sign in to Nuvio.** Tap **Approve on Nuvio**, sign in on Nuvio's website, and approve the code.
   Nuvio's site then shows your account page, with profiles and addons. That page isn't the app:
   **switch back to Nuvio Web** (swipe up from the bottom, or use the app switcher). It shows
   **Who's watching?** within a few seconds.
4. Pick your profile. Your addons, library and progress are the ones on your own Nuvio account.
5. Tap **Share**, then **Add to Home Screen**, so Nuvio opens like an app.

## Good to know

- Starting a film takes about 10 to 20 seconds. Sources marked **Needs backend** are converted for the
  iPhone, which is what takes the time.
- Subtitles default to English. If they're out of time, open the subtitle menu and tap
  **Try the next best match**.
- The **ⓘ** button in the player shows playback details. A screenshot of it helps if something's wrong.
- Your invite code can be revoked at any time by whoever gave it to you.
- This is an independent project, not an official Nuvio app. Its source code is at the link in
  **Settings → About**.
